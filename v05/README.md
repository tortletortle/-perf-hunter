# PERF HUNTER V0.5

Runtime-guided search and held-out confirmation for the two V0.4 issue-inspired adapters, plus an identical-program (A/A) control. Python 3.13.5; standard library only. From the repository root or the extracted portable bundle, run `python v05/search.py --baseline v04 --output results-v05`. Do not disable assertions. Runtime measurements vary with machine and load.

## Protocol
Three cases, two strategies (random and best-parent mutation), four search seeds (501–504), sixteen candidate evaluations per run, each with three paired blocks. Same initial workload and measurement seed per strategy; candidate streams diverge. Workload size fixed at 256; deepcopy varies atomic fraction and nesting; ZIP varies query count and starting prefix. Search ranks by median baseline/adapted time. The shortlist contains one maximum per case/strategy/seed (24 entries, not necessarily distinct inputs). Ten fresh sequential subprocesses (seeds 900–909) each reevaluate all finalists in shuffled order, five paired blocks per finalist. The worker median, not individual timing blocks, is the unit of inference. One-sided exact sign test against median ratio <=1.10 and Bonferroni adjustment across all 24 finalists, nominal family alpha 0.05. This requires all ten worker medians to exceed 1.10 (adjusted p=0.0234375). The sign test assumes independent worker observations; shared host/time effects may violate that assumption. No formal real-world error-rate guarantee.

## Results
384 search evaluations (1152 paired blocks); 240 finalist/worker observations (1200 paired blocks). Median search / independent median ratios: deepcopy random 2.017/1.957, mutate 2.481/2.116; ZIP random 1.671/1.394, mutate 1.767/1.408; A/A random 1.386/1.003, mutate 1.096/0.999. All sixteen positive entries confirmed and all eight A/A entries rejected. Five of eight A/A search maxima exceed 1.10 before confirmation. Maximum A/A search ratio 1.552. The saved results were checked for unique keys, timing ratios, median calculations, shortlist selection and all 24 verdicts. This is evidence of selection bias control on these cases, not a benchmark-wide sensitivity/specificity estimate.

## Limitations
Two issue-inspired adapters, not exact upstream revision pairs or new defect discoveries. In particular, the V0.4 ZIP workload is only a name-list mechanism proxy for zipp #106, not an exact `Path.glob` reproduction; see V0.7 for the PR #113 / PR #122 tradeoff. Four search seeds and small workload spaces; no evidence of general mutation superiority. Equal evaluation budget, not equal elapsed time. Sequential subprocesses on one host; no CPU pinning or cross-machine replication. Alpha and threshold are experimental settings. Raw data are in the downloadable bundle. Next: independent upstream revision pairs, realistic workload grammars, randomized interleaving across machines and budget-aware confirmation.
